Four changes in this task:

**1. Embed migrations (DEPLOY-02, DEPLOY-04):**
In `backend/internal/storage/sqlite/db.go`:
- Add `import "embed"` and declare `//go:embed migrations/*.sql` with `var migrationsFS embed.FS` — BUT embed directives work relative to the file's package directory. Since migrations/ is at `backend/migrations/` not `backend/internal/storage/sqlite/migrations/`, you CANNOT embed from db.go directly.
- Instead: Create `backend/migrations/embed.go` with:
  ```go
  package migrations
  import "embed"
  //go:embed *.sql
  var FS embed.FS
  ```
- Update `db.go` to accept the embed.FS: change `runMigrations(db *sql.DB)` to `runMigrations(db *sql.DB, fs embed.FS)` and use `fs.ReadFile(filename)` instead of `os.ReadFile(m.file)`. Update the migration file paths to just the filename (e.g., `"001_create_users.sql"` not `"migrations/001_create_users.sql"`).
- Also optimize: Fetch all applied versions in a single query before the loop instead of one query per migration:
  ```go
  rows, _ := db.Query("SELECT version FROM schema_migrations")
  applied := map[int]bool{}
  for rows.Next() { var v int; rows.Scan(&v); applied[v] = true }
  ```
- Remove `"os"` import from db.go if no longer needed.

**2. Fix fly.toml (DEPLOY-01):**
Remove the conflicting `memory = '1gb'` line. Keep only `memory_mb = 256` (or bump to 512 if appropriate — check current production needs). The [[vm]] section should be:
```toml
[[vm]]
  cpu_kind = 'shared'
  cpus = 1
  memory_mb = 256
```

**3. Graceful shutdown (DEPLOY-05):**
In `backend/cmd/server/main.go`, replace `log.Fatal(http.ListenAndServe(...))` with proper signal handling:
```go
srv := &http.Server{Addr: ":" + port, Handler: router}
go func() { if err := srv.ListenAndServe(); err != http.ErrServerClosed { log.Fatal(err) } }()
quit := make(chan os.Signal, 1)
signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)
<-quit
ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
defer cancel()
srv.Shutdown(ctx)
```
Add imports: `"context"`, `"os/signal"`, `"syscall"`, `"time"`.

**4. Structured logging (DEPLOY-08):**
Replace `log` with `log/slog` in main.go:
- Set default handler: `slog.SetDefault(slog.New(slog.NewJSONHandler(os.Stdout, nil)))` at the start of main()
- Replace `log.Printf("Måltiden startar på :%s", port)` with `slog.Info("server starting", "port", port)`
- Replace `log.Fatal(...)` calls with `slog.Error(...)` followed by `os.Exit(1)` (slog has no Fatal)
- Do NOT add slog to every handler/service — that would be too invasive. Just replace the existing log calls in main.go and db.go for now.

**1. Configurable CORS (AUTH-06):**

- Change CORS function signature to accept allowed origins: `func CORS(allowedOrigins []string) func(http.Handler) http.Handler`
- Build a `map[string]bool` from the slice for O(1) lookup
- Check `origin` against the map instead of hardcoded strings

- Update router.go where `middleware.CORS(mux)` is called — pass the origins.

**2. Health check with DB connectivity (DEPLOY-06, DEPLOY-10):**
In `backend/internal/api/handlers/health.go`:
- Change `Health` to be a method on a struct that holds `*sql.DB`: `type HealthHandler struct { db *sql.DB }`
- `func (h *HealthHandler) Check(w http.ResponseWriter, r *http.Request)` that:
  - Sets `Content-Type: application/json`
  - Pings the database with a 2-second timeout context
  - Returns `{"status":"ok","db":"connected"}` with 200 if healthy
  - Returns `{"status":"error","db":"disconnected"}` with 503 if db.PingContext fails
- Update router.go to create HealthHandler with db reference and use `healthHandler.Check` instead of `handlers.Health`.

- Wrap the router in request ID middleware in router.go (or main.go), inside the CORS wrapper:

Do NOT add rate limiting (AUTH-05) in this plan — it requires choosing a library and adds complexity. Defer to a future improvement or document as a recommendation.

  <action>
  **DATA-01: Registration transaction**
  1. In `auth_service.go`, the `Register` method creates 3 entities (household, user, member) across 3 separate INSERT statements. If user creation fails after household is created, orphan data remains.
  2. AuthService needs access to `*sql.DB` for transaction. Add `db *sql.DB` field to AuthService struct. Pass it via NewAuthService (from router.go, where `db` is available).
  3. Rewrite `Register` to:
     a. `tx, err := s.db.Begin()` + `defer tx.Rollback()`
     b. Create household via `tx.Exec(...)` directly (inline the SQL from householdStorage.Create)
     c. Create user via `tx.Exec(...)` directly (inline the SQL from userStorage.Create)
     d. Create household member via `tx.Exec(...)` directly (inline the SQL from householdStorage.AddMember)
     e. `tx.Commit()`
  4. Alternative simpler approach: Add Tx methods to user_storage and household_storage (like the existing `AddMemberTx`, `RemoveMemberTx` pattern). Then in Register: `tx, err := s.db.Begin()`, call storage Tx methods, commit.
  5. **Use approach 4** — it follows the existing Tx pattern in the codebase (AddMemberTx, MarkInviteUsedTx, etc.).
  6. Add `CreateTx(tx *sql.Tx, household *domain.Household) error` to HouseholdStorage.
  7. Add `CreateTx(tx *sql.Tx, user *domain.User) error` to UserStorage.
  8. In Register: begin tx, call CreateTx for household, CreateTx for user, AddMemberTx for member, commit.

  **DATA-02: Zero-recipe guard**
  1. In `menu_service.go`, `Generate` already returns `nil, nil` when `len(recipes) == 0`. The handler already checks for nil and returns 400 with `no_recipes_available`. This is already handled!
  2. Verify the handler code — if it returns a different error message, align it. Looking at menus.go line 40: `http.Error(w, '{"error":"no_recipes_available"}', http.StatusBadRequest)` — this is correct.
  3. No code change needed for DATA-02.

  **router.go update:**
  1. Update `NewAuthService(userStorage, householdStorage)` → `NewAuthService(db, userStorage, householdStorage)` to pass db for transactions.

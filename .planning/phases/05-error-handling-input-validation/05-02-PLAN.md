**1. Add `DecodeJSON` helper to response.go** that combines MaxBytesReader + Content-Type check + JSON decoding:
```go
// DecodeJSON reads and decodes a JSON request body with size limit and Content-Type check.
// Returns false if decoding failed (error already written to w).
func DecodeJSON(w http.ResponseWriter, r *http.Request, maxBytes int64, dst interface{}) bool {
    // Check Content-Type (VALID-07)
    ct := r.Header.Get("Content-Type")
    if ct != "" && !strings.HasPrefix(ct, "application/json") {
        WriteError(w, http.StatusUnsupportedMediaType, "content_type_must_be_json")
        return false
    }
    // Limit body size (VALID-02)
    r.Body = http.MaxBytesReader(w, r.Body, maxBytes)
    if err := json.NewDecoder(r.Body).Decode(dst); err != nil {
        if err.Error() == "http: request body too large" {
            WriteError(w, http.StatusRequestEntityTooLarge, "request_too_large")
        } else {
            WriteError(w, http.StatusBadRequest, "invalid_request")
        }
        return false
    }
    return true
}
```

Use `const maxBodySize = 1 << 20` (1MB). Replace all `json.NewDecoder(r.Body).Decode(&req)` calls with `DecodeJSON(w, r, maxBodySize, &req)` in: auth.go (Register, Login), household.go (JoinHousehold, UpdateMemberStatus), recipes.go (Create), menus.go (Generate), shopping.go (UpdateItem).

**2. Add `ValidateUUID` helper to response.go** (VALID-04):
```go
func ValidateUUID(w http.ResponseWriter, id, paramName string) bool {
    if id == "" {
        WriteError(w, http.StatusBadRequest, paramName+"_required")
        return false
    }
    if _, err := uuid.Parse(id); err != nil {
        WriteError(w, http.StatusBadRequest, "invalid_"+paramName)
        return false
    }
    return true
}
```

Note: Entity IDs in this codebase use prefixed UUIDs (e.g., `rec_` + UUID). The `uuid.Parse()` will fail on prefixed IDs. Instead, validate that the ID is non-empty and matches the expected prefix pattern. Use a simpler validator:
```go
func ValidateID(w http.ResponseWriter, id, paramName string) bool {
    if id == "" {
        WriteError(w, http.StatusBadRequest, paramName+"_required")
        return false
    }
    // IDs are prefix + UUID (e.g., "rec_abc123..."), minimum length is prefix + UUID (3+1+36 = 40)
    if len(id) < 4 {
        WriteError(w, http.StatusBadRequest, "invalid_"+paramName)
        return false
    }
    return true
}
```

Apply to all path parameter extractions:
- household.go: `memberID` in UpdateMemberStatus and `targetID` in RemoveMember
- shopping.go: `itemID` in UpdateItem
- Also validate `menuID` query parameter in shopping.go (GetShoppingList, UpdateItem)

**3. Fix recipes.go GetByID** (VALID-03) — replace manual `strings.Split(path, "/")` with `r.PathValue("id")`. The route is already registered as `GET /recipes/{id}` in router.go, so PathValue works.

**4. Fix offers.go coordinate validation** (VALID-06) — when `lat`, `lng`, or `radius` query params are present but fail to parse, return 400 instead of silently falling back to defaults. Extract a `parseLocationParams` helper:
```go
func parseLocationParams(r *http.Request) (lat, lng float64, radius int, err error) {
    lat, lng, radius = defaultLat, defaultLng, defaultRadius
    if latStr := r.URL.Query().Get("lat"); latStr != "" {
        lat, err = strconv.ParseFloat(latStr, 64)
        if err != nil { return 0, 0, 0, fmt.Errorf("invalid lat") }
    }
    // same for lng, radius
    return lat, lng, radius, nil
}
```
Apply in SearchOffers, GetDiscounts, GetStores — call `parseLocationParams`, if err return `WriteError(w, 400, "invalid_coordinates")`.

Also deduplicate the excludeStores parsing (used in SearchOffers and GetDiscounts) into a `parseExcludeStores(r)` helper.

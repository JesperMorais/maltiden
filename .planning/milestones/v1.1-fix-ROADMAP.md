## Phases

### Phase 4: Critical Security & Data Integrity

**Goal**: Fix all authentication bypass vulnerabilities, IDOR issues, transaction safety, and database integrity (FIX-PLAN Batches 1-2)
**Depends on**: v1.0 Pre-Fix milestone complete
**Plans**: 3 plans
**Verified**: 10/10 must-haves passed

Plans:

- [x] 04-01: JWT Auth Hardening (AUTH-01, AUTH-02, AUTH-03)
- [x] 04-02: IDOR Protection & Transaction Safety (AUTH-04, DATA-01, DATA-02)
- [x] 04-03: Database Integrity (DATA-03, DATA-04, DATA-05, DATA-06, DATA-09)

**Details:**
- JWT secret validation at startup (minimum 32 characters)
- HS256 algorithm pinning in token validation (prevents "none" attack)
- Authentication middleware on shopping list endpoints
- IDOR protection: menu/shopping operations verify household ownership
- Registration flow wrapped in database transaction
- Foreign keys enabled via DSN `_foreign_keys=on`
- SQL injection fixed via `json_each()` for tag filtering
- UUID-based menu day IDs prevent collisions
- Composite index on `menu_days(menu_id, date)`

### Phase 6: Performance & Database

**Goal**: Fix external API performance (Tjek caching, concurrent fetching) and database configuration (WAL mode, connection pool, N+1 queries) (FIX-PLAN Batches 5-6)
**Depends on**: Phase 4 (FK enforcement enables reliable query optimization)
**Plans**: 2 plans
**Verified**: 14/14 must-haves passed

Plans:

- [x] 06-01: Tjek API Optimization (PERF-02, PERF-03, PERF-08, PERF-09, PERF-10)
- [x] 06-02: Database Configuration & Query Optimization (PERF-01, PERF-04, PERF-05, PERF-06, PERF-12)

**Details:**
- In-memory TTL cache for Tjek API responses (1-hour TTL, ~600x speedup on cache hit)
- Concurrent catalog fetching with semaphore (5 goroutines max, ~5x speedup)
- Retry logic with exponential backoff for transient failures
- WAL mode with `synchronous=NORMAL` for concurrent reads/writes
- Connection pool: 25 max open, 5 idle, 5min lifetime
- Batch recipe fetching eliminates N+1 in shopping list generation (5 queries → 1)
- 5-second context timeouts on all storage operations
